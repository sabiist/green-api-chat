# GREEN-API Chat

Минимальный пользовательский интерфейс для обмена текстовыми сообщениями через GREEN-API. Задание выполнено в варианте без MAX: в качестве транспорта предполагается инстанс GREEN-API для WhatsApp/Telegram, если он доступен в кабинете GREEN-API. Интерфейс и сценарий сохранены по ТЗ: вход по учётным данным инстанса, создание чата, отправка сообщения, получение ответа.

## Что реализовано

- ввод `apiUrl`, `idInstance`, `apiTokenInstance`;
- проверка инстанса через `getStateInstance`;
- создание чата по номеру или `chatId`;
- отправка текстового сообщения через `sendMessage`;
- получение входящих уведомлений через `receiveNotification`;
- подтверждение обработки через `deleteNotification`;
- обработка только текстовых сообщений (`textMessageData`, `extendedTextMessageData`);
- статусы исходящих сообщений: отправляется / отправлено / ошибка;
- сохранение учётных данных, чатов и сообщений в `localStorage` браузера;
- адаптивный интерфейс в духе минимального мессенджера.

## Ограничения

- Это frontend-only приложение: данные живут в `localStorage` текущего браузера и не синхронизируются между устройствами.
- Для живой проверки нужен авторизованный инстанс GREEN-API.
- Для Telegram/WhatsApp вместо MAX используйте соответствующий тип инстанса GREEN-API и корректный `chatId`.
- Для WhatsApp `chatId` обычно выглядит как `79991234567@c.us`. Для Telegram-инстансов GREEN-API используйте `chatId`, который приходит во входящих уведомлениях или указан в документации вашего типа инстанса.
- Бот/получатель должен быть доступен выбранному инстансу: в Telegram пользователь должен взаимодействовать с ботом, в WhatsApp номер должен быть доступен инстансу.

## Локальный запуск

```bash
pnpm install
pnpm dev
```

Откройте адрес, который покажет Vite, обычно:

```txt
http://localhost:3000
```

## Production build

```bash
pnpm build
pnpm preview
```

## Сценарий проверки

1. Введите `apiUrl`, `idInstance`, `apiTokenInstance`.
2. Создайте чат: укажите номер телефона или `chatId` получателя.
3. Отправьте текстовое сообщение.
4. Ответьте на сообщение в мессенджере.
5. Ответ должен появиться в чате через polling `receiveNotification`.
